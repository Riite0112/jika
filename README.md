# 時価(Jika)

時価(Jika)は、ECサイトの商品価格の横に「労働何時間分か」をそっと表示するChrome拡張機能です。金額を自分の時間に置き換えることで、買う直前の一瞬に冷静さを取り戻し、衝動買いを抑えるきっかけを作ります。

## インストール

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このリポジトリのフォルダを選択します。

## 初期設定

1. Chromeのツールバーから「時価(Jika)」を開きます。
2. 「時給」に自分の時給を入力します。初期値は `1,500円` です。
3. 月収から計算したい場合は「月収」と「月間労働時間」を入力します。
4. 手取り換算を使う場合は「手取り換算で計算」をONにします。額面の `0.8` 倍で簡易計算します。

## 対応サイト

初期状態では次のサイトで動作します。

- Amazon.co.jp
- 楽天市場
- Yahoo!ショッピング
- メルカリ

対応サイトを追加する場合は、`manifest.json` の `content_scripts[0].matches` に対象URLを追加してください。

```json
"matches": [
  "*://*.amazon.co.jp/*",
  "*://*.example.com/*"
]
```

追加後は `chrome://extensions` で拡張機能を再読み込みしてください。

## プライバシー

時価(Jika)は外部サーバーへ通信しません。時給、最低表示金額、無効化したドメインなどの設定はすべて `chrome.storage.sync` に保存され、価格検出と換算はブラウザ内だけで行われます。
